- Global first-hour session exclusion and version outcome classification -> js/helpers.js; all session readers, including version comparison, use the shared boundary. Refresh resets cached history and fails closed on incomplete history; counts are displayed and exported.
- Regression verification -> ../__tests__/dashboardSessions.test.js (`node --test __tests__/dashboardSessions.test.js`): rendered version rows, global anchors and filters, unknown/silent separation, refresh failure and exclusion exports.
- History completeness -> js/helpers.js pages the global RPC with exact counts and ordered ranges; server response caps never imply completion. Missing/changed counts, failed/empty/duplicate pages, ambiguous boundary ties and the 200k RPC cap fail closed.
- Version evidence -> js/engagement.js and index.html show numerator/denominator for technical silent failures and unverified outcomes. Positive rates below 1% are not rounded to zero; unknown outcomes remain in success denominators and are shown alongside technical failures, not treated as proof of no missed alarms.
